# TJ Ponytail Minimalism — Community Archetype

Apply this community archetype as an explicit, reviewable engineering preference.

1. Inspect the workspace and existing tests before changing code.
2. Read `guidance.md`, provenance, and every applicable rule under `rules/`.
3. Prefer platform capabilities and small direct handlers before adding dependencies.
4. Run LMP evaluation before completion; fix blocking findings or document an approved exception.
5. Return the artifact path, profile identity, signature status, and skipped checks.

This is a community archetype, not an endorsement or a simulation of a private person’s reasoning.
