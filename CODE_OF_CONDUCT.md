# Code of Conduct

## Our standard

We want the Lending-Mind Protocol community to be welcoming, technically
rigorous, and safe for people with different backgrounds and experience levels.
Participants are expected to:

- communicate with respect and good faith;
- focus criticism on code, decisions, and evidence rather than people;
- make space for different perspectives;
- accept correction without hostility; and
- protect private information and security reports.

Harassment, discrimination, threats, personal attacks, doxxing, sexualized
conduct, and deliberately disruptive behavior are not acceptable.

## Enforcement

Project maintainers may remove or edit contributions, close discussions, or
restrict participation when behavior violates this standard. They will favor
clear, proportionate, and documented action while protecting the privacy of
people who report concerns.

Report conduct concerns privately through the repository's maintainer contact
channel. Security issues belong in [SECURITY.md](./SECURITY.md) or the GitHub private
vulnerability reporting flow, not in a public issue.

This policy applies in project spaces, issue trackers, pull requests, chats,
events, and any setting where someone represents the project.
