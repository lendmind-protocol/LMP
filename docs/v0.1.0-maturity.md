# v0.1.0 maturity scorecard

This scorecard is the release contract for LMP. A green local test is evidence
for the named behavior; it is not permission to claim an external service,
public deployment, or production adoption result that was not exercised.

## Explicit blockers before publishing

1. The GitHub Pages deployment at `https://lendmind-protocol.github.io/LMP/`
   serves the static app. Release verification still needs to retrieve the
   expected `/registry.json` and manifest bytes during a tagged release run.
2. Default public profiles now have detached signatures, public keys, and
   manifest digests. They still need independently verifiable immutable IPFS
   or OCI distribution. Placeholder CIDs, hashes, or trust anchors are not
   acceptable evidence.
3. Official MCP conformance and cross-platform release artifacts require their
   respective external runners or suites. Local protocol tests do not replace
   those checks.
4. A human usability/adoption pilot remains separate from automated
   qualification and benchmark evidence.
5. Developers must use the repository's pinned Rust 1.98.1 toolchain. The
   system Rust 1.75 installation produces invalid dependency metadata before
   linting begins; the pinned stable toolchain passes Clippy with
   `-D warnings`.

## Reproducible release commands

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
./orchestrator/test_registry_sync.sh
./orchestrator/test_signatures.sh
docker build -t lmp-sandbox:local orchestrator
python3 orchestrator/qualification_suite.py --output lmp-test-results/qualification-result.json
python3 orchestrator/real_world_benchmark.py --lmp target/release/lmp --output lmp-test-results/real-world
# Package and verify the current-host release archive:
mkdir -p lmp-test-results/release-artifacts-local
python3 orchestrator/package_release_artifact.py \
  --target x86_64-unknown-linux-gnu \
  --binary-dir target/release \
  --output-dir lmp-test-results/release-artifacts-local
(cd lmp-test-results/release-artifacts-local && sha256sum *.tar.gz > SHA256SUMS)
python3 orchestrator/release_artifact_gate.py \
  lmp-test-results/release-artifacts-local \
  --targets x86_64-unknown-linux-gnu
# After the cross-platform workflow downloads archives:
python3 orchestrator/release_artifact_gate.py dist
```

Only artifacts with the expected scenario counts, zero failed transitions,
and complete prerequisite metadata may be used as release evidence.
