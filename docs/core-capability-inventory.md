`ROADMAP.md`. It is a source-oriented companion to the user-facing [web
capability inventory](../apps/docs/content/docs/operations/capability-inventory.mdx).
It records implementation ownership and the evidence boundary without turning
fixtures or planned integrations into production claims.

## Explicit fixture and external boundaries

- Fixture repositories and generated result files are disposable test inputs
  and evidence outputs, not evidence about arbitrary production repositories.
  Runs default to an automatically cleaned temporary directory; an explicit
  `LMP_TEST_BED_DIR` uses a new subdirectory and preserves earlier runs.
- Placeholder or unsigned registry metadata is intentionally rejected by the
  release gate and must not be presented as a trusted public profile.
- Docker, public deployment, IPFS/OCI pinning, official host conformance, and
  independent adoption require fresh evidence from their respective systems.
- This inventory does not modify the protected architecture, concept,
  solution, onboarding, security, notice, roadmap, or context documents.
