# Governance

Community archetypes describe practices without cloning a person. Individual or
organization authorship is accepted only with verified opt-in, attribution, and
provenance. Rule changes require tests, remediation text, maintainer review,
and semantic-versioning rationale. A breaking enforcement change increments a
major version; additive rules are minor; corrections are patch releases.

Signatures are rotated by publishing a new key and version, retaining the old
public key for historical verification, and documenting revocation or loss.
Promotion is reviewable evidence-backed evolution: `artifact promote` writes a
proposal and never modifies a Mind Package automatically.
