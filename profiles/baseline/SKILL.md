# LMP Baseline

Use this profile as the default local-first engineering contract.

1. Inspect the repository, tests, and configuration before proposing a change.
2. Read `guidance.md` and the rules under `rules/` before making decisions.
3. Prefer advisory evaluation first; use only explicitly approved commands.
4. Run LMP evaluation before finishing and fix error-level findings or record an approved exception.
5. Return the evidence artifact path, findings, skipped checks, and final status.

The profile guides visible engineering decisions and produces reviewable evidence. It does not request hidden reasoning or replace human review.
