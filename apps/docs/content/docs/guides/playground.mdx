# Inspect a policy fixture

This page is a bounded fixture walkthrough, not a code-generation showcase. It
shows how a selected Mind names a rule, declares a threshold, records scope,
and produces a result for a known example. The reference code is explanatory;
it is not generated by an agent and it is not a measurement from the Rust
evaluator.

Edit the candidate only to see the preview become **not evaluated**. That is
intentional: a browser component has no workspace, package digest, parser,
changed-file scope, or Docker runtime. For an actual decision, run the [CLI
evaluation](/docs/reference/cli) or [MCP integration](/docs/guides/mcp-integration).
The resulting artifact contains the package digest, checked-file scope,
findings, and privacy metadata.
