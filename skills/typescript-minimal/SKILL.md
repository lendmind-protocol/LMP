# LMP TypeScript Minimal

Use this profile when maintaining TypeScript or Node.js workspaces.

1. Inspect existing modules, tests, compiler configuration, and dependency manifests first.
2. Read `guidance.md` and the rules under `rules/` before editing source.
3. Prefer native APIs and small, explicit modules; keep strict TypeScript semantics intact.
4. Run LMP evaluation before finishing and remediate error-level findings with approved checks only.
5. Return the evidence artifact path and clearly distinguish passed, revised, blocked, and skipped checks.

This wrapper exposes the profile’s visible instructions; it never asks for private reasoning or treats a policy pass as universal quality proof.
